## How to Copy GitHub URLs

1. Navigate to the file in GitHub
2. Click the file in the repository browser
3. Copy the URL from the address bar
4. Replace `github.com/USERNAME/smartcare-clinic/blob/main/` with your actual GitHub username

OR

Use this template and replace `YOUR_USERNAME`:
```
https://github.com/YOUR_USERNAME/smartcare-clinic/blob/main/[FILE_PATH]
```
