API ENDPOINTS (14 Core Endpoints)

Authentication:
  POST   /api/auth/login                    - User login

Doctors:
  GET    /api/doctors                       - List all doctors

  PUT    /api/doctors/{id}                  - Update doctor

Patients:
  POST   /api/patients/register             - Patient registration
  GET    /api/patients/me                   - Get patient profile
  PUT    /api/patients/me                   - Update profile

Appointments:
  GET    /api/appointments/available-slots  - Get available slots
  POST   /api/appointments                  - Book appointment
  GET    /api/appointments/my-appointments  - View my appointments
  PUT    /api/appointments/{id}/status      - Update status

Medical Records:
  GET    /api/medical-history/patient/{id}  - Get medical history
  POST   /api/medical-history               - Record history

Prescriptions:
  GET    /api/prescriptions/appointment/{id} - Get prescriptions
  POST   /api/prescriptions                 - Create prescription

DEPLOYMENT INSTRUCTIONS
================================================================================

Option 1: Docker (Recommended)
  1. Navigate to project directory
  2. Run: docker-compose up -d
  3. Wait 30 seconds for services to be ready
  4. Access at:
     - Frontend: http://localhost
     - Backend: http://localhost:8080
     - API Docs: http://localhost:8080/swagger-ui.html

Option 2: Manual Setup
  1. Ensure MySQL 8.0 and MongoDB 5.0 are running
  2. Initialize database: mysql < database/init.sql
  3. Build backend: mvn clean install
  4. Run backend: mvn spring-boot:run
  5. Serve frontend: npx http-server frontend
